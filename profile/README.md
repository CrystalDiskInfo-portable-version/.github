# Project Overview

CrystalDiskInfo is a disk health monitoring utility for Windows designed to display information about HDDs, SSDs, and supported storage devices.

It provides access to S.M.A.R.T. data, drive temperatures, health indicators, firmware information, interface details, power-on statistics, and other storage diagnostics in a compact interface.

# S.M.A.R.T. Monitoring

CrystalDiskInfo displays S.M.A.R.T. attributes reported by compatible storage devices.

Depending on the drive, available information can include:

- Reallocated sectors
- Power-on hours
- Power cycle count
- Temperature
- Read and write statistics
- Error information
- Remaining-life indicators
- SSD-specific health data

The exact attributes available depend on the drive manufacturer, controller, and storage technology.

---

# Drive Health

CrystalDiskInfo summarizes available diagnostic information into an easy-to-read health status.

This can help users identify drives that may require closer inspection or replacement.

A warning does not automatically confirm imminent drive failure, while a normal status does not replace regular backups.

---

# Temperature Monitoring

Storage temperature can be monitored directly from the application when supported by the drive.

Temperature monitoring is particularly useful for:

- NVMe SSDs
- Gaming PCs
- Workstations
- Laptops
- Servers
- High-performance storage
- Systems with limited airflow

Consistently high temperatures may indicate cooling or airflow issues.

# HDD and SSD Support

CrystalDiskInfo can provide diagnostic information for many common storage configurations, including supported:

- SATA HDDs
- SATA SSDs
- NVMe SSDs
- External drives
- USB-connected storage
- Multi-drive systems

Available information can vary depending on the enclosure, USB bridge, controller, and device firmware.

# NVMe Monitoring

For compatible NVMe SSDs, CrystalDiskInfo can display useful health and usage information such as temperature, operating hours, data usage, and other device-reported statistics.

This makes it useful for monitoring modern high-performance SSD configurations.

# Important Notes

CrystalDiskInfo is a monitoring and diagnostic utility. It cannot guarantee whether or when a storage device will fail.

Important data should always have independent backups, especially when a drive reports abnormal S.M.A.R.T. values, unusual temperatures, read/write errors, or other warning indicators.

---

# Troubleshooting

If a drive is not detected correctly, check its connection, controller configuration, enclosure compatibility, and Windows device detection.

External USB enclosures may not expose every S.M.A.R.T. attribute to monitoring software.

If CrystalDiskInfo reports a warning, review the affected attributes and back up important data before performing additional diagnostics.
